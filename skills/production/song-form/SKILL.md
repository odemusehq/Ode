# Song Form

Read song_get and lead_sheet_read. Establish section positions in beats from the actual meter. Use song_create_locator and lead_sheet_update to retain the form; use ordinary clip writers for material. No fixed form is required.

Discover the named tools with `tool_search` using `names` and the appropriate group before calling them. Read only the references needed for the current task; the artist's current direction overrides stylistic advice.

- `references/craft.md`: optional detailed techniques and examples.

Optional sub-skills:
- `production/song-form/pop`: Pop song structure on top of the song-form skill, for planning and fixing pop forms in place — reaching the first chorus early, short intros, verse–pre-chorus–chorus with post-chor.
