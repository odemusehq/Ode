# Arrangement

Read section clips and intended roles. Write only the requested changes through track_create_midi_clip, track_create_audio_clip, midi_clip_set_notes, clip_set and locator tools. Preserve approved hooks and deliberate space.

For a whole song, develop the hook and a representative verse-to-chorus passage with the chosen actual sources before extending the form. Keep structure revisable unless the artist has chosen it. Assess whether the chorus changes focus, groove, register, texture or performance in the intended way; section names alone do not create contrast. A repeated hook can stay exact while the accompaniment, phrasing and transitions develop around it. Variation is purposeful rather than mandatory at fixed bar intervals.

Read `references/craft.md` when building the full arrangement or diagnosing a flat one. Use `production/song-form` and its relevant genre child when section order or duration needs work, and return to `production/sound-design` when the source itself limits the result. Build changes with supported native clips, notes, samples and parameters; for an unexposed automation/editor operation, give the musician its exact intended native step.

Use the tool schemas exposed by the SDK; discover missing schemas with `ToolSearch` when available. Read only the references needed for the current task; the artist's current direction overrides stylistic advice.

- `references/craft.md`: optional detailed techniques and examples.
