# Mastering

Inspect the actual Main chain, artist intent and available processed Main route. Make justified native parameter changes and compare real captures. Native display values are settings, not LUFS, true-peak or gain-reduction measurements. Unexposed measurements remain unavailable. Saving/exporting the final song is done by the musician in Live.

Discover the named tools with `tool_search` using `names` and the appropriate group before calling them. Read only the references needed for the current task; the artist's current direction overrides stylistic advice.

- `references/craft.md`: optional detailed techniques and examples.
