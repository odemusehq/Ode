# Vocals

Distinguish a sung recording from a MIDI guide. Edit supplied audio through exposed native tools, or write requested guide/harmony notes through SDK writers. Lyricist handles words. Ode has no singing renderer, voice-cloning or vocal-generation service; do not treat a synth as a finished singer.

Read `production/live-controls` to prepare the real input/track, guide the singer and operate native recording when they are ready. Work with their actual performance. Native clip pitch/markers and explicit warp-marker edits are available; complete comping, phrase fades and detailed automation can require a musician-performed native step. Reveal the clip/device, explain that specific action and inspect the result afterwards.

Discover the named tools with `tool_search` using `names` and the appropriate group before calling them. Read only the references needed for the current task; the artist's current direction overrides stylistic advice.

- `references/craft.md`: optional detailed techniques and examples.

Optional sub-skills:
- `production/vocals/harmonies`: Write and fix vocal harmony lines and stacks on top of the vocals skill, as MIDI guides placed in the Set — choosing the interval (thirds, sixths, fourths, fifths, octaves) from th.
