# Idea

Use the artist's actual intention and material. Ask lyricist for any proposed wording. Genre and remembered preferences are context, not a fixed method. When material is generic or stuck, try sensory exploration or semantic/rhyme alternatives; when a verse repeats itself, ask what new understanding it adds and how it changes the returning hook. Forward the relevant reference through `lyricist.references` rather than assuming it reaches the model.

Discover the named tools with `tool_search` using `names` and the appropriate group before calling them. Read only the references needed for the current task; the artist's current direction overrides stylistic advice.

- `references/craft.md`: optional detailed techniques and examples.
