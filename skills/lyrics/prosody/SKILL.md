# Prosody

Ask lyricist with the real words, exact melody and intended delivery. Consider meaning, stress, rhyme and musical setting together. A speech-like stress pattern or balanced form is an option, never a universal requirement.

Discover the named tools with `tool_search` using `names` and the appropriate group before calling them. Read only the references needed for the current task; the artist's current direction overrides stylistic advice.
