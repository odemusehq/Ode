# Syllables

Ask lyricist with the exact text, pronunciation and relevant melody coordinates. Counts, stress and delivery come from that configured model, not a local dictionary. Melisma, pickups, elision and unequal counts can be intentional.

Discover the named tools with `tool_search` using `names` and the appropriate group before calling them. Read only the references needed for the current task; the artist's current direction overrides stylistic advice.
